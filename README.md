# BLOCKS — AR Building Prototype

V1 prototype for a spatial block-building game.

Core loop:
1. Open on an HTTPS site.
2. Allow camera access.
3. Move the phone to scan the space.
4. Show your hand.
5. Pinch thumb + index finger to grab a block.
6. Move your hand.
7. Release to place the block.
8. Blocks near another block magnetically snap into place.

## Important
This is an experimental V1. Browser camera and AR behavior varies by device/browser. Test on a real iPhone over HTTPS.

The prototype uses:
- Three.js
- Zappar Three.js
- MediaPipe Hands
